# Timeline of Us

A premium cinematic Next.js App Router experience built with Tailwind CSS, Framer Motion, GSAP ScrollTrigger, Lenis smooth scrolling, and a subtle React Three Fiber particle background.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Customize

- Edit timeline stories in `app/data/moments.ts`.
- Replace remote Unsplash images with your own images when ready.
- Update the handwritten letter text in `app/components/LetterModal.tsx`.
- Replace the background audio URL in `app/components/ExperienceShell.tsx` if you have a personal song file.
